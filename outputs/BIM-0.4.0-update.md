# BIMViewer 0.4.0

本轮仅更新网页。Revit 导出器仍为 0.3.0，不需要重新加载 DLL，也不需要为这些网页功能重新导出模型。刷新 http://127.0.0.1:5173/ 后打开原 GLB 即可。

## 已实现

- 大画布、底部工具栏；模型树和属性按需展开，默认收起。
- 模型树按类别展开后才生成子项，搜索时展开匹配分支。
- 两点距离、XYZ 分量、三点角度，距离默认毫米；多条结果、撤销未完成点、单条删除、全部清除。
- 测量线、测量点和随视图移动的结果标签。
- 自由漫游、速度调节、截图下载、全屏，以及显示设置本地记忆和恢复默认。
- 保留原始材质、分类着色、白模、透视、边线、网格、曝光、剖切、选择、定位、隐藏和隔离。

## 操作

底部尺子进入测量。距离点两个点，角度点三个点，第二个点为角顶点。测量针对可见模型表面；隐藏构件和被剖切裁掉的表面不会被拾取。

脚印进入自由漫游。点击画布获取焦点后，W/A/S/D 移动，按住鼠标拖动转向，R/F 升降，Esc 退出。切换窗口、进入输入框或工具面板后停止移动。速度单位为米/秒。

相机按钮下载 PNG，包含当前模型和测量标注，不包含周围的侧栏。全屏时打开模型树或属性，会先退出全屏。

设置中的显示模式、边线、网格、曝光以及漫游速度会保存在当前浏览器。刷新后保留；不保存模型文件和测量记录。

## 边界

- 测量基于三角网格表面取点，不具备 CAD 端点捕捉能力，不能代替施工放样或精确净距验算。
- XYZ 是查看器坐标，Y 为竖直方向，并非 Revit 原始 Z-up 坐标。XYZ 分量显示绝对差值。
- 漫游允许穿墙，无碰撞、重力或自动贴地。
- 测量仅在本次模型会话保留，切换模型或刷新后清空；隐藏构件后已有标注仍保留，需自行删除。
- 不含体积、空间面积、最小净距、剖切封口、视点分享、批注文件和云端保存。

## 验证

- 23 项自动化测试全部通过；前端生产构建通过。
- 浏览器验证距离与 XYZ、90° 角度、多条结果、删除与清除、截图下载、设置刷新恢复、全屏和侧栏切换。
- 自由漫游前后画布像素发生变化，确认键盘移动生效；已验证 Esc 退出。
- 加载最新实际模型：10,749 构件、59 材质、11,992,909 三角形，材质颜色保留；构件选择、属性与定位正常。

构建仍提示主包超过 500 kB；此前依赖审计问题未在本轮进行破坏性升级处理。继续按本地 MVP 使用，不作为公网部署安全验收结果。
