# BIMViewer 0.5.0 更新说明

## 本次交付

1. 共享基础材质，选中构件单独高亮；避免所有网格各自克隆一份材质。
2. 默认开启空间合批。按空间块、材质、分类和属性布局合并静态不透明几何；支持在显示设置中关闭，回退到原始逐网格绘制。
3. 显示设置新增“惯性缓停”，默认关闭。旧设置没有该字段时也按关闭处理。松手后不再惯性滑动，画面静止后不再提交渲染；诊断面板的“持续渲染”是显式压力测试例外。
4. 性能面板新增累计渲染帧、合批状态/数量、共享/选中材质数及合批缓存数组增量。

## 同条件性能对比

约 532 MB 的机电模型，同一版本、同一视角、1280×654 缓冲、像素比 1、原始材质显示、边线关闭。

| 指标 | 关闭合批 | 开启合批 |
| --- | --- | --- |
| Draw Calls | 11,777 | 1,797 |
| FPS（导出采样） | 18.2 | 37.6 |
| 每帧提交三角形 | 12,005,557 | 12,005,557 |
| 共享基础材质 | 108 | 108 |

绘制调用下降约 84.7%，该组采样帧率约为 2.1 倍。关闭合批的对照组已经包含材质共享，不能把它当成完全未优化的 0.4.1。旧版 10.5 至 12.4 FPS 是另一轮测量，环境负载不同，不用于宣称严格倍数。

对应报告：`bim-050-batched-report.json`、`bim-050-unbatched-report.json`。数值会随设备、视角和后台负载变化；GPU 执行时间仍未采集。

## 正确性与限制

- 原始几何保留用于精确拾取、测量和回退，不降低几何精度。隐藏、隔离、选择通过合批索引更新及独立选中绘制保持构件 ID。
- 大模型实际拾取仍返回 Element ID 6359615。隔离后仅 1 次调用、12 个三角形；隐藏后提交量减少 12 个，恢复后回到原总数。
- 透明构件保留独立绘制。开启构件边线或透视模式会暂时退出合批，避免边线和透明排序回归。
- 本版没有引入 LOD、重复几何实例化或渐进式调度，相关统计仍如实为零。
- 合批构建会增加首次准备时间和 CPU 内存。本模型增加约 416 MiB 几何数组；总额外合批数组预算为 512 MiB，临时构建分配和浏览器其他内存不包括在该预算内。关闭合批会保留 CPU 缓存供快速切换，但停用的 GPU 缓冲会释放；要完全避免合批缓存，请关闭后重新打开模型。
- 原始几何与合批数组暂时并存，尚不适合无限放大模型规模。下一阶段需进一步做导出期复用、减面/LOD与分块卸载。
- 页面仍有轻量输入检查循环；“停止渲染”指静止时不再调用场景渲染，不是停止一切 JavaScript。

## 验证与使用

36 项测试通过，类型检查和生产构建通过，保留既有的大文件块警告。新增测试覆盖变换后几何边界、源数组不变、显隐索引恢复、透明/镜像/材质/分类隔离、空间分块、内存预算及惯性默认值和设置读写。

浏览器补充验证：旋转松手后累计主循环渲染帧在两次间隔检查中均保持 22；分类着色、剖切、透视回退和小模型边线回退正常。惯性开启状态在新页面读取成功，恢复默认后变为关闭。390×844 窄屏模型可见，桌面尺寸已恢复。浏览器错误和警告记录为空。大模型透视模式仍较慢（本次单帧 CPU 提交约 284 ms），本轮没有针对全场透明绘制做提速。

访问 http://127.0.0.1:5173/。底部“设置”中可切换“空间合批”和“惯性缓停”；底部“性能监控”中观察计数。静止测试务必取消“持续渲染”。

本次仅更新网页端，BIMExporter 保持 0.3.0，无 DLL 更新，不需要重启 Revit。
