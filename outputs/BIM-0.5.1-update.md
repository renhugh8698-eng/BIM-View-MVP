# BIMViewer 0.5.1

- 开启构件边线不再关闭空间合批。
- 先逐构件提取边线，再按原空间批次合并，保留构件之间的边界；不是只给合并后的整体提取外轮廓。
- 边线索引跟随构件显隐、隔离和选中状态更新，并应用剖切面。透明或其他独立绘制构件继续使用各自边线。
- 透视模式仍保留原始绘制路径。
- 首次生成边线仍可能短暂停顿，缓存会增加内存；性能面板合批数组增量包含边线缓存。原 512 MiB 预算仅约束表面几何，边线缓存另计。

按用户要求，本次没有运行测试、构建或浏览器验证，不宣称已有新的性能实测结果。上一版的验证结果不自动覆盖此次改动。Revit 插件未更新。

下一步建议：先由用户查看本次边线与构件操作效果；再将首次边线生成及合批构建改为分批可取消任务，减少界面停顿；随后推进重复几何分析与安全实例化，降低双份几何内存；根据面数热点加入曲面简化和 LOD；最后扩展分块加载、卸载和缓存预算。
