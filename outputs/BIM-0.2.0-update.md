# BIM MVP 0.2.0 更新说明

## 本次完成

- 导出器改用 Revit `CustomExporter` / `IExportContext`，按当前三维视图导出。
- 使用实例与链接变换栈，坐标只变换一次；GLB 根节点统一转换英尺/Z-up 到米/Y-up。镜像实例处理三角形绕序，法线使用逆转置变换。
- 构件内按颜色与透明度合并网格，保留法线与 UV，并对完整顶点属性去重。
- 保留稳定构件 ID；链接构件 ID 包含宿主和链接实例路径，区分同一链接模型的不同放置实例。
- 模型树与构件属性内嵌到 GLB。新版只需打开 `model.glb`；`model.json` 仍输出为可选旁文件。旧版 GLB + JSON 加载继续兼容。
- 修正窄屏相机取景，保留拾取、属性、隐藏、隔离和模型树操作。
- 已将 Revit 2020 插件清单指向 `BIMExporter/bin/Release/0.2.0/net48/BIMExporter.dll`。

## 立即使用

1. 保存工作，关闭全部 Revit 窗口，再启动 Revit 2020。运行中的旧插件不会自动热替换。
2. 打开需要导出的三维视图，确认类别可见性、隐藏构件和剖面框符合预期。
3. 使用 BIMExporter 重新导出到新目录。原有导出文件不会自动修复。
4. 刷新 <http://127.0.0.1:5173/>，只选择新版 `model.glb`。
5. 对照 Revit 检查门窗位置，尤其是平移、旋转、镜像和嵌套族；检查透明玻璃、楼层与构件属性。
6. 若有链接模型，测试同一链接放置两次，确认位置正确、两个实例的构件 ID 不冲突。另检查隐藏和剖面框范围。

## 已执行验证

- Revit 2020 API 引用下的 C# 插件构建通过，零警告、零错误。
- C# GLB 写入器可执行测试通过：文件头、块长度、内嵌属性、坐标根矩阵、法线、UV、顶点去重、索引与透明材质。
- 前端 11 项测试通过，包括用户原有导出包兼容性和 C# 生成的单文件 GLB；前端生产构建通过。
- 浏览器验证通过：单 GLB 加载、模型树、拾取与属性、隐藏、隔离、恢复、旋转；桌面与 390px 窄屏无横向溢出，截图像素检查非空白。
- 浏览器验证使用合成墙体/玻璃模型，不是真实 Revit 导出。尚未在 Revit 内执行新版导出，不能据此宣称真实门窗偏移已验收。

## 更新方式与范围

后续发布先更新项目中的 `PluginVersion` 并构建，再运行 `BIMExporter/Install-Revit2020.ps1` 更新清单。安装脚本自动读取版本目录；重启 Revit 后加载新版。本次未实现运行中插件热加载。

本阶段采用未压缩的正确性基线。跨实例几何复用和 Draco 压缩留待真实模型验收后实施；暂不导出纹理图片、高级外观、RPC 外观或灯光。UV 数据已保留，但不等于已支持贴图。

实现参考了用户提供的 [cowboy1997/Revit2GLTF](https://github.com/cowboy1997/Revit2GLTF) 的 CustomExporter 路线；未整包替换现有产品。详细构建、测试与 Revit 验证步骤见源码包内 README。
